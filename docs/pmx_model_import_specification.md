## 1. PMX ファイルフォーマット解析仕様 (`mmd_core/pmx.py`)

PMX は MMD の現代的な標準モデル形式であり、ヘッダーにエンコーディングやインデックスサイズを動的に切り替えるグローバル設定テーブルを持っています。

### 1-1. バイナリ構造一覧

- **シグネチャ**: `PMX `（4バイト ASCII）
- **バージョン**: `2.0` または `2.1`（float32）
- **グローバル設定配列 (8バイト)**:
  - エンコーディング: 0（UTF-16LE）または 1（UTF-8）
  - 追加UV数: 0〜4
  - 頂点インデックスサイズ: 1, 2, 4 バイト
  - テクスチャインデックスサイズ: 1, 2, 4 バイト
  - 材質インデックスサイズ: 1, 2, 4 バイト
  - ボーンインデックスサイズ: 1, 2, 4 バイト
  - モーフインデックスサイズ: 1, 2, 4 バイト
  - 剛体インデックスサイズ: 1, 2, 4 バイト
- **モデル情報セクション**:
  - モデル和名・英名、コメント和文・英文
- **頂点データセクション**:
  - 位置座標（`x, y, z`）: float32 x 3（MMD左手系からMaya右手系へZ反転）
  - 法線（`nx, ny, nz`）: float32 x 3
  - テクスチャUV（`u, v`）: float32 x 2（Maya用 `1.0 - v` 反転）
  - 追加UV: 各種拡張パラメータ
  - ウェイト変形方式: BDEF1, BDEF2, BDEF4, SDEF, QDEF
- **面（ポリゴンインデックス）セクション**:
  - 3頂点で1面を構成する頂点参照配列
- **テクスチャテーブルセクション**:
  - テクスチャファイルパス（文字列リスト）
- **材質（マテリアル）セクション**:
  - 拡散色（RGBA）、鏡面反射色（RGB・光沢度）、環境光色（RGB）
  - 描画フラグ: 両面描画、地面影、セルフシャドウマップ、セルフシャドウ描画、輪郭線描画
  - 輪郭線色（RGBA）、輪郭線サイズ
  - 通常テクスチャインデックス、スフィアテクスチャインデックス（乗算/加算/サブテクスチャ）
  - 共有Toonフラグ（0: 個別テクスチャ, 1: 共有toon01.bmp〜toon10.bmp）
- **ボーンセクション**:
  - ボーン和名、英名、初期位置座標（`x, y, z`）、親ボーンインデックス、変形階層
  - ボーンフラグ: 接続先指定、回転可能、移動可能、表示、操作可能、IK、付与親回転/移動、軸固定、ローカル軸、変形後変形、外部親変形
- **モーフセクション**:
  - モーフ和名、英名、操作パネル（眉・目・口・その他）、モーフ種類（頂点・UV・ボーン・材質・グループ）
- **表示枠セクション**:
  - 表情枠・ボーン表示枠のグループ構成
- **剛体セクション**:
  - 剛体和名、英名、関連ボーン、衝突グループ、非衝突マスク、形状（球/箱/カプセル）、寸法、位置、回転、質量、減衰、反発、摩擦、剛体タイプ（Kinematic/Dynamic/Aligned）
- **Joint（拘束）セクション**:
  - Joint和名、英名、接続剛体A/B、位置、回転、移動制限、回転制限、ばね定数

## 2. 堅牢化バイナリパーサー仕様 (`mmd_core/pmx.py`)

国内外の多様な配布モデルや破損リスクのあるPMXファイルであっても、読み込みエラーによるクラッシュを起こさず安全にロードを行うための保護仕様です。

- **多重文字エンコードフォールバック**:
  - ヘッダーで指定されたエンコードフラグ（UTF-16LE / UTF-8）に加え、フラグ偽装や不正バイト列を含むファイルに対して CP932（Shift_JIS）、GBK、EUC-JP の多段階フォールバックを自動試行。
  - 不明な不正バイトシーケンスは安全な代替文字へ置換し、デコード失敗による中断を防止。
- **ストリームリーダーの安全終端パディング**:
  - ファイル末尾が途切れた欠損PMXやデータ境界超過時、例外でクラッシュさせずにゼロパディングされた安全なダミーバイト列を返却して終端を保護。
  - float値に含まれる非数値（NaN）や無限大（Inf）を自動検出し、0.0 へ安全クランプ。
- **頂点ウェイト・インデックスの自動修復**:
  - 各頂点のボーンウェイト合計が 0 または NaN になっている不良頂点を検出した場合、第1ボーンへウェイト 1.0 を自動割り当てしてメッシュ形状崩壊やスキニング計算例外を防止。
  - ボーンインデックスや材質インデックスの範囲外参照を上限値・下限値へ安全クランプ。
- **不正モーフオフセットの自動除外**:
  - モデル内の存在しない頂点インデックスやボーンインデックスを参照している不正なモーフオフセット定義を自動検出し、不正な要素のみを除外してモデル全体の正常なインポートを継続。

## 3. スキニング方式の対応状況

PMX規格で定義されているスキニング方式について、Maya の SkinCluster 上で以下のように最適化・対応しています。

| スキニング種別 | MMD仕様 | Mayaでの対応方式 | 特徴・品質 |
| :--- | :--- | :--- | :--- |
| **BDEF1** | 単一ボーン追従 (ウェイト 1.0) | 通常のリニアスキニング | 剛体パーツや装飾品等で破綻なく高速変形 |
| **BDEF2** | 2ボーン線形補間 | 通常のリニアスキニング (`setWeights`) | 人体の肘や膝など一般的な関節部位に対応 |
| **BDEF4** | 4ボーン線形補間 | 4ボーン加重リニアスキニング | 肩回りや複雑な衣装の自然な変形を再現 |
| **SDEF** | 球面デュアルクォータニオン変形 | デュアルクォータニオン近似 / 線形正規化 | 関節屈曲時の体積潰れ（キャンディ包み現象）を抑制 |
| **QDEF** | デュアルクォータニオン変形 | デュアルクォータニオンブレンド | 4ボーン以上の滑らかなねじれ変形を保持 |

## 4. モーフ高速直接書き込み仕様 (Sparse Target Delta Direct Write)

従来のメッシュ複製ループ（`mc.duplicate` / `mc.delete`）による多大なメモリ割り当てとGCオーバーヘッドを廃止し、Maya API 2.0（`maya.api.OpenMaya`）を用いた「ブレンドシェイプターゲット差分直接書き込み方式」を実装しています。

- **空 BlendShape ノードの生成**:
  - ベースメッシュのみを引数として `mc.blendShape(model_mesh_node)` を呼び出し、余分なジオメトリを持たない空のブレンドシェイプノードを瞬時に生成。
- **プラグ探索とデータストリーム**:
  - `MFnDependencyNode` から `inputTarget[0].inputTargetGroup[m_idx].inputTargetItem[6000]` プラグを取得。
  - プラグの子属性から、頂点座標配列プラグ（`inputPointsTarget`）および移動対象コンポーネントリストプラグ（`inputComponentsTarget`）を特定。
- **スパース差分データ（Sparse Target Delta）の直接注入**:
  - 移動が発生する頂点インデックスのみを `MFnSingleIndexedComponent(kMeshVertComponent)` に登録。
  - 差分移動ベクトル（`dx * scale`, `dy * scale`, `-dz * scale`, 1.0）のみを `MPointArray` に構築。
  - `MFnPointArrayData` および `MFnComponentListData` を用いて、Maya 内部のデータスロットへ直接一括書き込み。
  - 100個以上の頂点モーフを持つ大規模モデルであっても、数秒台でモーフの構築が完了する高速性を達成。
- **正規エイリアス登録とUI・VMD整合性保証**:
  - 各モーフターゲットウェイト（`weight[m_idx]`）に対して、Maya内部およびUI表示で安全な正規エイリアス名 `temp_bs_{m_idx:03d}_{safe_morph_name}` を自動付与。
  - モデル構造辞書（`morph_structure_map`）に日本語名および英名とエイリアス属性名のマッピングを記録。
  - チャネルボックス、シェイプエディタ、表情操作UI（`morph_window.py`）、およびVMDインポートでの一貫したキーフレーム適用と相互運用性を維持。

## 5. `mmdToonShader` 材質モーフ二重透過・受光制御

Viewport 2.0 OGSFX シェーダー（`mmdToonShader`）と連携し、材質モーフによる動的なパーツ透明化や頬染め表現を忠実に再現します。

- **二重透過アトリビュート配線**:
  - シェーダー内部の直接アルファ（`diffuseAlpha`）および逆転透過（`transparencyR/G/B`）の双方へ、材質モーフのウェイトオフセットを連動配線。
  - パーツ非表示時（アルファ 0.0）における不要な白浮きや境界のチラつきを抑止。
- **受光遮断（`diffuse = 0.0`）による影残り防止**:
  - 非表示化されたパーツが平行光や環境光に反応して空中に不自然な落ち影を残さないよう、ディフューズ受光遮断を自動連携。
- **加算・乗算演算ノードネットワーク**:
  - 材質モーフの乗算（Multiply）と加算（Add）を正しく合成するユーティリティノード（`plusMinusAverage` / `multiplyDivide`）を構築し、複数モーフの同時適用時にも破綻のない質感ブレンドを実現。
