# MMDモーション (VMD) ・ポーズ (VPD) ・カメラ・音源 入出力技術仕様書

> [!NOTE]
> 本詳細技術仕様書は、AI によって作成・整理されたドキュメントです。内容はソースコードおよび開発記録をもとに記述していますが、実際の動作と細部が異なる場合があります。

本ドキュメントは、「MMD Tools for Maya」における MMD モーション形式（VMD）およびポーズ形式（VPD）のバイナリ・テキスト解析から、Maya 上でのボーンアニメーション、モーフアニメーション、カメラアニメーション、WAV 音源同期配置、およびシーン姿勢・アニメーションカーブのエクスポートに至る詳細な技術仕様を定めたものです。

---

## 1. VMD ファイルフォーマット解析仕様 (`mmd_core/vmd.py`)

VMD (Vocaloid Motion Data) は MMD のモーション記録バイナリ形式です。

### 1-1. バイナリ構造一覧
- **ヘッダー (30バイト)**:
  - シグネチャ: `Vocaloid Motion Data 0002`（版数表記含む）
- **モデル名 (20バイト)**:
  - Shift_JIS エンコーディングによる対象モデル名（カメラモーションの場合は「カメラ・照明」等）
- **ボーンキーフレームセクション**:
  - キーフレーム総数（4バイト符号なし整数）
  - 各フレームデータ（111バイト）:
    - ボーン名: 15バイト (Shift_JIS)
    - フレーム番号: 4バイト (uint32)
    - 平行移動ベクトル: `tx, ty, tz` (float32 x 3)
    - 回転クォータニオン: `qx, qy, qz, qw` (float32 x 4)
    - 補間曲線パラメータ: 64バイト (X軸, Y軸, Z軸, 回転の4種 x 4制御点 `x1, y1, x2, y2`)
- **モーフ（表情）キーフレームセクション**:
  - キーフレーム総数（4バイト uint32）
  - 各フレームデータ（23バイト）:
    - モーフ名: 15バイト (Shift_JIS)
    - フレーム番号: 4バイト (uint32)
    - ウェイト値: float32（0.0 〜 1.0）
- **カメラキーフレームセクション**:
  - キーフレーム総数（4バイト uint32）
  - 各フレームデータ（61バイト）:
    - フレーム番号: 4バイト (uint32)
    - 目標注視点距離: float32
    - 目標注視点位置: `tx, ty, tz` (float32 x 3)
    - 回転オイラー角: `rx, ry, rz` (float32 x 3, ラジアン)
    - 補間曲線パラメータ: 24バイト
    - 視野角（FOV）: 4バイト uint32 (度数)
    - パースペクティブフラグ: 1バイト bool

## 2. アニメーション変換・適用エンジン仕様 (`vmdpaimaya.py`)

### 2-1. 座標系変換とクォータニオン解析
MMD の右手座標系と Maya の座標系の整合性を保つため、以下の変換規則を適用します。

- **移動ベクトルの変換**:
  - $X_{maya} = X_{vmd}$
  - $Y_{maya} = Y_{vmd}$
  - $Z_{maya} = -Z_{vmd}$ （Z軸方向の符号反転）
- **回転クォータニオンの変換とオイラー角算出**:
  - MMD クォータニオン $(q_x, q_y, q_z, q_w)$ に対し、Z軸反転に合わせて $( -q_x, -q_y, q_z, q_w )$ への符号補正を実施。
  - Maya のデフォルト回転順序（XYZ）に基づき、クォータニオンからオイラー角（Degree）へ数学的に変換。
  - オイラー角のジンバルロックおよび 180度反転（フリップ現象）を防止するため、直前フレームの角度連続性を考慮したアンロール（Euler Filter 相当）処理を適用。

### 2-2. ベジェ補間曲線の Maya カーブ Tangent マッピング
VMD の補間曲線パラメータ（各 0〜127 のバイト値）は、3次ベジェ曲線の2つの制御点 $(x_1, y_1)$ および $(x_2, y_2)$ を表します。

- 制御点座標の正規化:
  - $P_1 = (x_1 / 127.0, y_1 / 127.0)$
  - $P_2 = (x_2 / 127.0, y_2 / 127.0)$
- Maya キーフレーム接線への反映:
  - Maya の `keyTangent` コマンドを使用。
  - 出発接線（OutTangent）の角度・ウェイトを $P_1$ から算出。
  - 到着接線（InTangent）の角度・ウェイトを $P_2$ から算出。
  - これにより、MMD 特有の緩急（イーズイン・イーズアウト）を Maya ビューポート上で一致させて再生。

### 2-3. フル DAG パス解決と同名ノード衝突回避
大規模なモデルや複数モデルがシーン内に存在する場合、単一の名前（例: `arm`）では Maya 内で衝突（エラー）が発生します。

- **フルパス特定**:
  - `_resolve_full_joint_path` 関数により、ルートノードから目的のジョイントまでの絶対 DAG パス（例: `|model_group|master|center|...|arm`）を一意に特定。
  - 名前衝突による別モデルへの誤ったキーフレーム適用を防止。

### 2-4. 日英ボーン相互照合による自動適用
VMD 内部のボーン名と Maya 内のジョイントの照合は、以下の多段階解決アルゴリズムによって行われます。

- モデル構造キャッシュ（`last_imported_structure.json`）の直接参照。
- 和名・英名の一致照合。
- `asset/bone_dict.py` による標準ボーン日英変換照合（海外製モーションや Blender から出力された英語名 `center`, `leg_L` 等を和名へ自動変換）。
- 左右表記ゆれ（`_L`/`_R` ↔ `左`/`右`）の正規化照合。
- モデル名プレフィックス（`koishi_` 等）の自動除去照合。

### 2-5. ひざジョイントの優先角度（preferredAngle）設定と脚IK逆折れ防止

MMDモデルの脚IKアニメーションを Maya 上で美しく安定して再現するため、ひざジョイントに対する優先角度設定と逆折れ抑止機構を搭載しています。

- **優先角度（`preferredAngle`）による屈曲方向の安定化**:
  - Maya の IK ソルバーは、ジョイントが一直線（180度）に伸びきった状態から曲がる際、初期の屈曲ヒントとして `preferredAngle` を参照します。
  - ひざジョイント（`左ひざ` / `右ひざ`）に対し、解剖学的に自然な屈曲軸（X軸正方向）へ適切な優先角度（`preferredAngleX = 60.0`）を設定することで、脚が曲がり始める瞬間の方向性を固定します。
- **逆関節・不自然な反転（フリップ）の防止**:
  - 激しいステップや深い屈伸、ジャンプ着地時などの極端なIKポーズにおいて、ひざが後ろ向きや横方向へ逆折れしてしまう不自然な反転現象を抑止します。
- **脚・ひざ方向（ポールベクター）追従との連動**:
  - `apply_leg_knee_orientation` による外開きポールベクター計算と連携し、しゃがみポーズやダンス中の自然な開脚ラインを破綻なく維持します。

## 3. カメラ・音源（WAV）のタイムライン同期仕様

### 3-1. カメラモーションの適用 (`apply_camera_motion`)
- 専用の MMD カメラノード（`MMD_Camera`）をシーン内に自動生成。
- 注視点（エイム）とカメラ本体の階層構造を構築。
- VMD の距離パラメータおよび回転・注視点位置を Maya カメラのアトリビュートへキーフレーム記録。
- 視野角（FOV）を Maya カメラの `focalLength`（焦点距離 mm）へ画角変換して設定。

### 3-2. WAV 音源の自動読み込み・同期配置
- `wav/` フォルダ配下の音源、またはユーザー指定の `.wav` ファイルを検出。
- Maya の `sound` コマンドを使用し、タイムラインの 0フレーム目（または指定開始フレーム）にオーディオノードを配置。
- タイムスライダー再生時にリップシンクやダンスモーションと音声がリアルタイムで同期再生される環境を構築。

## 4. シーン初期化・クリーンアップ仕様 (`delete_mmd_scene_elements`)

GUI の「クリーンアップ」タブから実行可能な初期化機能の仕様です。

- **アニメーション初期化**:
  - MMD ボーンおよびモーフに打たれたアニメーションキーフレーム（`animCurve`）のみを一括削除し、モデルをバインドポーズまたは初期姿勢に復元。
- **全削除機能**:
  - MMD メッシュ、ジョイント階層、IK ハンドル、ライト、カメラ、オーディオノード、地面影関連ノード（`mmd_ground_shadow_grp`、プレーン、シェーダー、シェーディンググループ）、および未使用のシェーディングノードを一括消去。
  - オプションにより、ライトのみ・音源のみ・地面影のみの個別削除も選択可能。

## 5. VPDポーズデータ入出力エンジン仕様 (`mmd_core/vpd.py` / `vmdpaimaya.py`)

MMD公式のポーズデータ形式（`.vpd`）に対応したテキストパーサーおよび入出力エンジンです。

### VPDフォーマット構造
- **ヘッダー**: `Vocaloid Pose Data file`
- **モデル情報**: 親モデル名
- **ボーン姿勢リスト**:
  - 対象ボーン名
  - 平行移動ベクトル（X, Y, Z）
  - 回転クォータニオン（X, Y, Z, W）
- **モーフ表情リスト**:
  - 対象モーフ名
  - 表情ウェイト値（0.0 〜 1.0）

### ポーズの適用 (インポート) (試験的機能)
- VPDファイルを読み込み、現在フレームのモデルのボーン姿勢および表情モーフへ即時適用。
- オプションにより、適用と同時にカレントタイムスライダーフレームへキーフレームを自動登録可能。
- 操作UIは「その他機能」タブへ集約配置され、モデル選択・スケール指定・キーフレーム自動登録をワンストップで実行可能。

### 現在ポーズの保存 (エクスポート) (試験的機能)
- Maya上でポージングされた現在フレームのボーン回転（オイラー角からMMD左手系クォータニオンへ変換）およびブレンドシェイプモーフの現在値を抽出し、VPDファイルとして保存。

## 6. VMDモーションエクスポートエンジン仕様 (`mmd_core/vmd.py` / `vmdpaimaya.py`)

Maya上で作成・編集したキャラクターアニメーションやカメラワークを、公式MMD仕様のバイナリモーションファイル（`.vmd`）として出力します。

### アニメーションデータの抽出と逆算
- **ボーンキーフレーム**:
  - ジョイントの移動アニメーションカーブ（X, Y, Z）および回転カーブ（Euler角）を全フレーム走査。
  - Mayaのオイラー角からクォータニオンへ変換し、Z軸反転補正を行ってMMD座標系のキーフレームを生成。
- **表情モーフキーフレーム**:
  - `morph_<モーフ名>` またはブレンドシェイプターゲットのウェイトカーブを抽出してモーフキーフレームを生成。
- **カメラキーフレーム**:
  - Mayaカメラの位置、注視点（Aim）への距離、画角（FOV）をMMDカメラ座標系へ逆変換して記録。
- **重複キーの間引き軽量化**:
  - 静止フレームや同一値が連続する区間の冗長なキーフレームを自動検出して間引き、ファイルサイズを削減。

## 7. エクスポートUIの集約と操作性向上 (`ExportTabWidget`)

- **縦長レイアウトの解消**:
  - モーション(VMD)タブ内に混在していたエクスポート設定およびポーズ適用UIを整理し、エクスポート機能はエクスポートタブへ、ポーズ適用機能はその他機能タブへ集約。
- **「Maya → MMD (エクスポート)」タブへの機能集約**:
  - 「モデルデータ (.pmx) エクスポート」
  - 「MMD モーションデータ (.vmd) エクスポート (試験的機能)」
  - 「MMD ポーズデータ (.vpd) エクスポート (試験的機能)」
  の3大出力機能を1つのタブに集約配置。
- **スクロールエリア（QScrollArea）の導入**:
  - ウィンドウサイズがコンパクトな環境でも、すべての設定グループへスムーズにアクセス可能なレスポンシブなスクロール操作を実現。
