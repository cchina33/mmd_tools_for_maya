# DirectX .x ファイル (アクセサリ・ステージ) インポート技術仕様書

> [!NOTE]
> 本詳細技術仕様書は、AI によって作成・整理されたドキュメントです。内容はソースコードおよび開発記録をもとに記述していますが、実際の動作と細部が異なる場合があります。

本ドキュメントは、「MMD Tools for Maya」における DirectX 形式（`.x`）モデル・アクセサリ・ステージファイルの構文解析および Maya シーンへのインポート仕様を定めたものです。
3形式共通のメッシュ生成やシェーダー構築アーキテクチャについては、[pmx-pmd-x_specification.md](pmx-pmd-x_specification.md) をご参照ください。

---

## 1. DirectX .x ファイル構文解析仕様 (`mmd_core/x_file.py`)

DirectX 形式のモデル・アクセサリファイル（テキスト形式およびバイナリ形式）に対応した構文解析エンジンを搭載しています。

### 1-1. 字句解析器 (Tokenizer) 仕様

- **テンプレートブロックの自動スキップ**:
  - `template Mesh { ... }` や `template Material { ... }` など、ファイル先頭に定義されている DirectX 標準テンプレート定義ブロックを自動的に検出してスキップ。
- **区切り文字・コメントの正規化**:
  - 行頭や行末の不規則な改行コード、セミコロン（`;`）、カンマ（`,`）等の区切り文字を適切に正規化。
  - C++形式のコメント（`//`）およびスクリプト形式のコメント（`#`）を自動除外し、安定したトークンストリームを生成。
- **テキスト／バイナリ両形式の自動判別**:
  - ファイルヘッダーのシグネチャ（`xof 0302txt 0064` / `xof 0302bin 0064`）を識別し、テキストストリームまたはバイナリデコーダーへ安全に分岐。

## 2. ジオメトリ・材質データの抽出

構文木（トークン列）から、Maya のポリゴンメッシュ構築に必要なデータを抽出します。

- **頂点座標配列 (`Mesh` ブロック)**:
  - 頂点数および各頂点の 3D 座標（`float x, y, z`）を抽出。
  - MMD 左手系から Maya 右手系への変換のため、Z座標の符号を反転。
- **面インデックス配列**:
  - 各面を構成する頂点数および接続インデックスを抽出。
  - 4角形以上の多角形ポリゴンが含まれる場合、自動的に三角形ポリゴンへ分割（トライアンギュレーション）を実施。
- **法線ベクトル (`MeshNormals` ブロック)**:
  - 各頂点または各面の法線ベクトル（`nx, ny, nz`）を抽出し、スムーズシェーディングを確保。
- **テクスチャUV座標 (`MeshTextureCoords` ブロック)**:
  - 各頂点のテクスチャ UV 座標（`u, v`）を抽出。
  - Maya のテクスチャ座標系に合わせて `1.0 - v` 反転を実施。
- **材質リスト (`MeshMaterialList` ブロック)**:
  - 拡散反射色（RGBA）、鏡面反射色、環境光色を抽出。
  - 外部テクスチャファイル名（`TextureFilename`）を抽出し、相対パスまたは同一フォルダからの自動探索によりマテリアルへテクスチャをアサイン。

## 3. Maya シーンへの構築と用途

- **アクセサリ・ステージ用途**:
  - 主に背景ステージ、家具、武器や装飾品などのボーンを持たないスタティックメッシュとして Maya シーンへインポートされます。
- **共通メッシュビルダーとの連携**:
  - 抽出されたデータは共通の `MFnMesh.create` パイプライン（[pmx-pmd-x_specification.md](pmx-pmd-x_specification.md)）へ送られ、高速にポリゴンメッシュおよびシェーディングネットワークが構築されます。
- **アクセサリ追従アタッチ**:
  - インポート後、「その他機能」タブのアクセサリ追従アタッチ機能（`ui/accessory_dialog.py`）を使用することで、キャラクターモデルの手や頭などの指定ボーンへ即座に追従させることが可能です。
