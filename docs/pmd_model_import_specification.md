# PMD モデル (旧形式) インポート・自動変換技術仕様書

> [!NOTE]
> 本詳細技術仕様書は、AI によって作成・整理されたドキュメントです。内容はソースコードおよび開発記録をもとに記述していますが、実際の動作と細部が異なる場合があります。

本ドキュメントは、「MMD Tools for Maya」における MMD 旧標準モデル形式（PMD）の構文解析、最新 PMX 2.0 形式への自動変換パイプライン、および Maya シーンへのインポート仕様を定めたものです。
3形式共通のメッシュ生成やシェーダー構築アーキテクチャについては、[pmx-pmd-x_specification.md](pmx-pmd-x_specification.md) をご参照ください。

## 1. PMD ファイルフォーマット解析仕様 (`mmd_core/pmd.py`)

PMD は MMD の最初期から広く普及していた固定長バイナリ形式です。

### 1-1. バイナリ構造一覧

- **シグネチャ**: `Pmd`（3バイト ASCII）
- **バージョン**: `1.0`（4バイト float32）
- **モデル情報セクション**:
  - モデル名（20バイト Shift_JIS）
  - コメント（256バイト Shift_JIS）
- **頂点データセクション**:
  - 頂点数（4バイト uint32）
  - 各頂点（38バイト）:
    - 位置座標: `x, y, z`（float32 x 3）
    - 法線ベクトル: `nx, ny, nz`（float32 x 3）
    - テクスチャUV: `u, v`（float32 x 2）
    - ボーン番号: `bone1, bone2`（uint16 x 2、最大2ボーン対応）
    - ボーンウェイト: `weight`（uint8、0〜100）
    - エッジ非表示フラグ: 1バイト
- **面データセクション**:
  - 面頂点インデックス数（4バイト uint32）
  - 各面インデックス（uint16、3つで1面を構成）
- **材質データセクション**:
  - 材質数（4バイト uint32）
  - 各材質（70バイト）:
    - 拡散色（RGBA）、鏡面反射色（RGB・光沢度）、環境光色（RGB）
    - Toonインデックス（uint8、0〜9）
    - 輪郭線フラグ（uint8）
    - 面頂点数（4バイト uint32）
    - テクスチャファイル名（20バイト Shift_JIS、スフィアファイル名含む）
- **ボーンセクション**:
  - ボーン数（2バイト uint16）
  - 各ボーン（39バイト）:
    - ボーン名（20バイト Shift_JIS）
    - 親ボーン番号、尾ボーン番号
    - ボーン種別（回転、回転/移動、IK、IK先等）
    - IK親ボーン番号
    - ボーン座標: `x, y, z`（float32 x 3）
- **IKデータセクション**:
  - IKチェーンリスト、ターゲットボーン、ループ回数、制限角度
- **モーフ（表情）データセクション**:
  - 表情数、ベース表情頂点、各表情差分オフセット
- **拡張セクション（物理演算剛体・ジョイント）**:
  - 剛体データ（83バイト単位）: 形状、寸法、位置、回転、質量、減衰、反発、摩擦、剛体タイプ
  - Jointデータ（124バイト単位）: 接続剛体A/B、位置、回転、制限値、ばね定数

## 2. PMD → PMX 変換エンジン仕様 (`converters/pmd2pmx.py`)

最新の PMX 2.0 形式への移行を促進し、最新シェーダーや物理エンジンの性能を存分に引き出すため、インポート時の自動変換機能を提供しています。

- **`load2pmx` による構造変換**:
  - PMD バイナリデータを解析し、内部で最新 PMX 互換のデータ構造体へと変換。
  - ボーンの親子関係および IK セクションを PMX 形式の IK リンク構造へ正規化マッピング。
  - 材質の Toon インデックス（0〜9）を共有 Toon テクスチャパス（`toon01.bmp` 〜 `toon10.bmp`）へ自動変換。
  - テクスチャ名に含まれるスフィア指定（`*` 区切りの `.sph` / `.spa`）を自動検出し、乗算モード（Mode 1）および加算モード（Mode 2）へ正確に分離して登録。
- **剛体・Joint拡張情報の保持**:
  - PMD 拡張セクションに記録された物理パラメータを損なうことなく抽出し、PMX 規格の剛体・Joint オブジェクトへ展開。
- **ファイル保存 (`convert_pmd_to_pmx`)**:
  - `convert_pmd_to_pmx(pmd_path, pmx_path=None)`:
    PMD ファイルを解析し、同一フォルダ内に最新仕様の `<モデル名>.pmx` として保存。

## 3. インポート時の対話型変換プロンプト

- **GUI インポート時の検出**:
  - 「モデル」タブで `.pmd` ファイルが選択された場合、確認ダイアログを表示。
  - 「はい」を選択: 即座に同一フォルダへ `.pmx` を生成し、入力ファイルパスを自動更新した上で、未登録漢字チェックや剛体・Joint可視化生成を含む高機能な PMX インポートパイプラインを継続実行。
  - 「いいえ」を選択: 従来の PMD 読み込みを継続。
  - 「キャンセル」を選択: 処理を中断。
- **スタンドアロン変換機能**:
  - 「その他機能」タブ内に「PMD → PMX に変換」ボタンを配置し、モデルインポートを行わずに指定した PMD ファイルを単独で PMX へ変換・保存可能。
